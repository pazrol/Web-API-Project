EvenTix Events & Tickets card layout
The Events & Tickets section is now a responsive 3/2/1-column card grid. It retains the existing backend API, search, refresh, pagination, event details, booking and role-specific edit/delete actions. Category and venue names are fetched from existing API endpoints; missing labels fall back gracefully. No backend or database files are changed.

Install: Back up frontend-emil. Extract this ZIP into C:\xampp\htdocs\Web-API-Project\ and replace the frontend-emil files. Refresh Ctrl+F5.
